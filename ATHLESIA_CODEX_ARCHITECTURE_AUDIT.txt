Snapshot: 2026-09-05; HEAD and origin/main: 2824fb598f0942d27494d9b2aa22e4e46d37834e.
Scope: manifests, selected production implementations, runtime callers, recent commit diffs/statistics, and current T2-D test source. No builds, tests, network calls, dependency installation, or repository writes.

1. EXECUTIVE DIAGNOSIS

1) The repository is a collection of Cargo packages, not one root Cargo workspace. Root Cargo.toml:1-18 defines athlesia with no dependencies; M51's Cargo.toml:1-16 defines its own empty [workspace]. There are 32 package manifests total, including the root. Section 6 enumerates them.
2) Historical structural cognition and modern cognition form separate internal dependency components. M51 has seven direct dependencies: M45–M50 and self-bootstrap; all those dependencies terminate at M45. There is no transitive Cargo path to athlesia or any M23–M44 package. This is stronger evidence than absence of an immediately visible call. See section 6's manifest graph.
3) M51 genuinely invokes M46, M47, M48, M49, M50, but invocation is not full causal integration. OnlineCognitiveOrchestration::run executes perception → domain integration → executive → skill cycle → experimentation → anchor transition. Each receives its own caller-prepared input, not the preceding phase's detailed output. crates/athlesia_integrated_cognitive_agent/src/lib.rs:7744-7940.
4) Main M51 orchestration discards detailed world/skill/experiment results after ingestion, retaining contributions, executive selection, flags/status, and the anchor step. It does not own a persistent learned world, beliefs, or skill store. crates/athlesia_integrated_cognitive_agent/src/lib.rs:7488-7632, crates/athlesia_integrated_cognitive_agent/src/lib.rs:7649-7660, crates/athlesia_integrated_cognitive_agent/src/lib.rs:7830-7940.
5) OnlineRecurrentCognitiveLoop is a bounded fold over pre-supplied step inputs with predecessor feedback validation. It is not itself an observe/dispatch/learn environment driver. crates/athlesia_integrated_cognitive_agent/src/lib.rs:8066-8206.
6) The adapter supplies real interaction plumbing and transactional observation updates, but callers still supply cognitive inputs or an execution closure. crates/athlesia_arc_agi_3_adapter/src/cognitive_interaction_runtime.rs:81-207, crates/athlesia_arc_agi_3_adapter/src/live_environment_runtime.rs:226-260; crates/athlesia_arc_agi_3_adapter/src/bounded_episode_runtime.rs:148-265.
7) ARC perception currently projects cells and frame transitions; its default transition candidates are all empty. M46's object/persistence/change algorithms select supplied candidates. Temporal frames therefore do not establish autonomous object discovery in the live adapter. crates/athlesia_arc_agi_3_adapter/src/perceptual_ingestion_bridge.rs:200-290, crates/athlesia_core_knowledge_perceptual_grounding/src/lib.rs:2416-2510.
8) Post-M51 code adds useful independent bridges: perceptual evidence → transition-schema learning state, and grounded episodic memory → provisional executive authorization → feedback binding. These are real production APIs, but no call from the main orchestration or adapter to either bridge was found. crates/athlesia_integrated_cognitive_agent/src/lib.rs:8938-9031, crates/athlesia_integrated_cognitive_agent/src/lib.rs:9438-9500, crates/athlesia_integrated_cognitive_agent/src/lib.rs:10010-10073.
9) T2-C performs progressive exact correspondence through a source trajectory, with unknown outcomes represented by Option. It is not recursive abstraction or a persistent analogy-belief manager. Correspondence is recomputed from stored observations each call. crates/athlesia_meta_learning_skill_memory/src/lib.rs:7088-7584.
10) Noise safeguards exist: confidence floors, strict correspondence bindings, support-cluster tie abstention, and filtering by whether a transition changes state. They do not implement a general repeated-contradiction detachment lifecycle. crates/athlesia_meta_learning_skill_memory/src/lib.rs:7164-7440.
11) Stop/continue logic already exists. M48 values evidence-weighted, controllable progress minus cost; M50 checks resolution, cycle budget, useful experiments, measured progress and EIG. The missing coherence is feedback/state ownership and propagation of these decisions, not necessarily a missing metacognition module. crates/athlesia_executive_agency/src/lib.rs:3914-4198, crates/athlesia_autonomous_active_experimentation/src/lib.rs:6975-7251.
12) M50 is evaluated after executive selection, and its stop status does not independently veto dispatch. Dispatch checks executive authority. M45's final sparse orchestrator is not called by the audited main M51 runtime. crates/athlesia_integrated_cognitive_agent/src/lib.rs:7820-7938, crates/athlesia_integrated_cognitive_agent/src/lib.rs:8362-8430, crates/athlesia_mindstone_sparse_cognition/src/lib.rs:5756-5875.
13) Exact structural equality has real authority: M45's collision-safe identity compares structures; M51 validates exact anchors/provenance; T2 correspondence checks exact bindings. This valuable invariant should survive integration. It does not prove every older fingerprint-based API is collision-safe. crates/athlesia_mindstone_sparse_cognition/src/lib.rs:3355-3399, crates/athlesia_integrated_cognitive_agent/src/lib.rs:5273-5357, crates/athlesia_meta_learning_skill_memory/src/lib.rs:7098-7130.
14) T2-C is committed at HEAD; only T2-D is currently untracked. T2-D asks for 12 cold versus 6 transfer interactions in synthetic worlds. Those are assertions, not results established by this audit. crates/athlesia_integrated_cognitive_agent/tests/t2d_progressive_transfer_under_transient_noise.rs:486-521.

15) Ingested result structures are supplied by the request, not synthesized from the detailed layer result: perception copies request.grounded_state(), domain copies request.learned_state(). Bounds/digests validate aspects of the computation but do not establish semantic equality between that computation and the adopted structure. This is a particularly important authority gap. crates/athlesia_integrated_cognitive_agent/src/lib.rs:1128-1177,1802-1858.

4. LEARNING PATHS

Persistent effects are conditional on an owner retaining the returned state. A pure transformation can implement learning, but invoking it and dropping its result does not close a learning loop.

• Experience → context/action attempt count → ModelFreeExplorationMemory → select prefers least-attempted admitted action → changes future exploration. This is active in T-series drivers; no main M51/adapter caller found. It is coverage-directed, not estimated information gain. crates/athlesia_mindstone_sparse_cognition/src/lib.rs:5972-6047, crates/athlesia_mindstone_sparse_cognition/src/lib.rs:6100-6150; T2-D test:164-194, 233-259.
• Environment consequence → controlled GroundedTransformationEpisode → retained schema-learning episodes → TransitionSchemaInduction on accumulated episodes → future hypotheses. Production update API exists; later behavioral reader must be supplied by caller, not main M51. crates/athlesia_integrated_cognitive_agent/src/lib.rs:9438-9500.
• Grounded episodes → explanatory version-space synthesis → support/opportunity/counterexample counts and active hypotheses → explanatory prediction/factorized action discrimination. These later readers are implemented in M47; no main M51 call found. Re-synthesis consumes history supplied by caller. crates/athlesia_universal_domain_learning/src/lib.rs:10322-10528, crates/athlesia_universal_domain_learning/src/lib.rs:10586-10620, crates/athlesia_universal_domain_learning/src/lib.rs:10725-10840.
• Prediction + outcome → model evidence statuses → caller-visible confirmation/counterevidence. GroundedPredictionOutcomeEvidenceEngine evaluates a frontier; persistence/reweighting is not established merely by returning evidence. crates/athlesia_universal_domain_learning/src/lib.rs:9865-10110.
• Experiment result → AutonomousOutcomeEvidenceUpdate → AutonomousHypothesisBeliefRevision → returned beliefs → later belief-driven proposal. Both updates exist, but run_cycle only consumes beliefs; an external closure must connect evidence/revision. crates/athlesia_autonomous_active_experimentation/src/lib.rs:1562-1730, crates/athlesia_autonomous_active_experimentation/src/lib.rs:2347-2570, crates/athlesia_autonomous_active_experimentation/src/lib.rs:7836-7858.

6. M23–M44 ↔ M46–M51 INTEGRATION RESULT

RESULT: MOSTLY DISCONNECTED, with newer parallel implementations of overlapping responsibilities. More precisely: the entire historical package component is unreachable from M51 through declared internal dependencies; M46–M50 are directly invoked but only partially integrated causally. This is not indirect integration through shared historical primitives: M45 defines CognitiveStructure independently (Atom/Ordered/Unordered), whereas historical crates depend on root structural types and RecursiveUnit. crates/athlesia_mindstone_sparse_cognition/src/lib.rs:473-506; src/lib.rs:1-30; crates/athlesia_recursive/src/lib.rs:1-74.

Cargo proof and complete package inventory follow. Short names below expand by prepending “athlesia_”; ROOT means package “athlesia”. Each manifest is the authority for dependencies; reverse dependents were computed by reversing those edges. “Reach” is directed reachability FROM M51, not whether a crate depends ON M51. Without an explicit bridge, internal recurrent advancement can overstate consequence integration. crates/athlesia_integrated_cognitive_agent/src/lib.rs:5273-5357, crates/athlesia_arc_agi_3_adapter/src/cognitive_interaction_runtime.rs:172-207.
